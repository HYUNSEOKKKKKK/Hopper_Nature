# Hopper 현재 모델 — 2026-09-21, 총질량 14 kg 보정본

사용할 파일은 **`Hop2_Parallel_20260820.urdf`**다. 현재까지 반영한 CAD·실측 보정을 유지하면서, 전체 실측 질량 **14 kg**에 맞추도록 모든 링크에 남은 질량을 같은 비율로 배분했다. 현재까지의 전달용 최종본이며, 모든 부품의 질량 분포와 동특성이 실측으로 확정되었다는 뜻은 아니다.

패키지를 풀고 이 URDF와 메시 파일의 상대 경로를 유지하면 된다. 함께 남아 있는 `hopper_cam.urdf`는 이번 작업의 갱신 대상이 아니다. 압축파일의 `_D151_provisional` 이름은 기존 파일과의 연속성을 위해 유지했다.

|---|---:|

사용자가 말한 10%는 방법의 예시로 해석했다. 실제 부족량을 기준으로 계산한 **약 6.16%**를 적용했다. 각 링크에 같은 g 수를 더하는 방식이 아니라, 기존 질량이 큰 링크에 그만큼 많은 질량을 배분하는 방식이다.

링크 i의 기존 질량을 mᵢ, 질량 중심 기준 관성 텐서를 Iᵢ, 무게중심 위치를 cᵢ라고 하면:

```text
α = 14 / 13.187198673293
mᵢ,new = α × mᵢ,baseline
Iᵢ,new = α × Iᵢ,baseline
cᵢ,new = cᵢ,baseline
```

관성은 대각성분뿐 아니라 `ixy`, `ixz`, `iyz`도 같은 비율로 조정했다. 각 링크 안에서 추가 질량이 기존 질량 분포를 따른다는 가정이다. 링크 좌표계, 무게중심 위치, 관성 좌표계 방향은 유지했다. 따라서 같은 자세에서 로봇 전체 무게중심도 유지된다. 기록된 많은 소수 자릿수는 계산 재현용이며 저울의 측정 정밀도를 의미하지 않는다.

## D110의 추가 46 g과 모터 관성

실물 D110이 CAD보다 46 g 무겁다는 새 정보는 기록했다. 사용자는 stator 권선에서 보드까지 이어지는 배선 등이 CAD에 빠졌을 가능성을 설명했다. 현재 46 g의 대수별 적용 범위와 정확한 위치는 따로 확정하지 않았다.

**이번에는 그 46 g을 별도로 더하지 않는다.** 전체 14 kg와의 차이 812.801326707 g에 포함된 것으로 취급하고, 다른 미확인 질량과 함께 전 링크에 비례 배분한다. 따라서 이 보정이 ‘D110 위치에 46 g을 정확히 배치했다’는 의미는 아니다.

`dynamics rotor_inertia`는 링크의 강체 질량 관성과 역할이 다르다. 기어열의 내부 회전을 출력축에 환산한 값이므로, 배선 등 미확인 질량을 반영하는 이번 링크 배율을 자동으로 곱하지 않았다. 모터 torque/velocity 한계도 이번 총질량 보정으로 바뀌지 않는다.

## 재현 및 다음 실측값 반영

- `calibration/baseline_before_global_mass_20260921.urdf`: 이번 전체 보정 직전 기준 모델. 실측·CAD 반영을 보존한 이력 파일이며 실행할 최종 모델은 아니다.
- `calibration/global_mass_normalization_20260921.json`: 정확한 배율, 링크별 전후 질량·COM·관성, 파일 해시, 가정 기록.
- `calibration/normalize_total_mass_20260921.py`: 고정된 기준 모델에서 현재 최종 URDF를 재생성하는 스크립트. 다시 실행해도 배율이 중복 적용되지 않는다.
- `calibration/global_mass_validation_20260921.json`: 독립 검증 결과.

패키지 루트에서 재생성하려면:

```bash
python3 calibration/normalize_total_mass_20260921.py
```

새 실측값을 받으면 먼저 **배율 적용 전 기준 모델**의 해당 부품 질량·배치를 교정하고, 새 기준 질량 합으로 `14 / 새 기준 질량 합`을 다시 계산한다. 이미 14 kg인 모델에 추가 질량을 그대로 더하면 미배분 질량을 이중 계산하게 된다. 현재 스크립트는 기준 파일 해시를 고정하므로 새로운 실측 반영은 별도 보정 리비전으로 관리한다.

## 확인 범위

이번 변경은 11개 링크의 질량 및 질량 중심 관성 6성분과 설명·기록이다. 모든 링크의 COM·관성축 방향, 관절 구조·원점·축·제한·감쇠·마찰·rotor_inertia, 메시·충돌 형상, 폐루프 pin 설정은 유지했다.

XML 구조, 최종 질량 합, 비례 배율, 양의 질량, 관성 텐서 양정치 및 주관성 삼각부등식, 기존 설정 보존 여부를 검증했다. 실제 동역학 시뮬레이터 구동 검증은 수행하지 않았다. 기존의 `rotor_inertia`와 `constraints/pin` 확장을 읽는 시뮬레이터 설정을 계속 사용해야 한다.

총질량을 맞추면 전체 중량 오차는 제거되지만, 미확인 질량의 실제 위치나 부품별 분포가 새로 확인되는 것은 아니다. 현재 전달본은 사용자가 선택한 비례 분포 가정에 따라 그 불확실성을 명시적으로 다룬 모델이다.
