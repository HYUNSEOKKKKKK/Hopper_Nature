3. 공통 원점에서 봉의 기여를 교체하고, 합성 무게중심을 다시 구한 뒤 관성을 새 무게중심으로 이동했다.

## 再現計算

`sl_measured_steel_inputs_20260921.json`에 갱신 전 링크 값, STEP 형상 물성, 좌표 변환, 실측값을 저장했다. `recalculate_sl_measured_steel_20260921.py`를 실행하면 `sl_measured_steel_results_20260921.json`을 재생성할 수 있다. Python과 NumPy가 필요하다. 입력은 갱신 전의 스냅샷이므로 재실행해도 보정값을 두 번 더하지 않는다.

이전 링크 질량을 m₀, COM을 c₀, COM 관성을 I₀, 이전·새 봉 질량을 mp₀/mp₁, 봉 COM을 cp, 봉 COM 관성을 Ip₀/Ip₁로 나타낸다. P(c) = (c·c)E − ccᵀ로 두면 다음과 같다.

```
Δm = mp₁ − mp₀
m₁ = m₀ + Δm
c₁ = (m₀c₀ + Δm cp) / m₁
I₁ = I₀ + m₀P(c₀) + (Ip₁ − Ip₀) + Δm P(cp) − m₁P(c₁)
```

봉의 COM 관성은 CAD 형상의 단위밀도 관성을 체적으로 나눈 값에 봉 질량을 곱해 구한다. OpenCascade에서 얻은 값은 역학 관성 텐서이므로 SolidWorks의 양의 관성곱 표기에 대한 부호 변환을 다시 적용하지 않는다.

## SolidWorks 재질 설정

S45C가 선택지에 있으면 선택한다. 없다면 대응 강종인 AISI 1045를 선택하고 밀도를 확인한다. 7850 kg/m³(7.85 g/cm³)는 이번 비교에 사용한 강철의 대표값이며 실물의 재질 검사값은 아니다. 대응 강종 근거: [JFS Steel S45C / AISI 1045 대응표](https://www.jfs-steel.com/en/product/S45C.html). 규격 간의 완전한 동일성을 의미하지는 않는다.

CAD 질량을 실측과 맞추려면, 원래 재질을 복제한 사용자 정의 재질에서 '밀도 = 실측 질량 / 현재 CAD 체적'으로 설정한다. 이번 체적 기준으로는 S 약 7869.90 kg/m³, L 약 7799.92 kg/m³이다. 형상·측정 오차를 포함하는 질량 보정용 유효밀도이며, 실제 강종이 서로 다르다는 의미는 아니다. 현재 CAD 체적이 다르면 그 체적으로 다시 계산한다.

재질 변경 후에는 질량 속성 덮어쓰기 설정도 확인하고 재계산한다. 최신 SolidWorks 어셈블리 물성치가 추후 제공되면 이번 형상·부품 배분 전제를 재확인할 수 있다. 이번 실측값의 반영은 완료했다.
