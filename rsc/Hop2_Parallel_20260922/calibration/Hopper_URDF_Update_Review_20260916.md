이 자료는 현재 파일을 직접 비교하고, 제공된 SolidWorks 물성치·STEP 배치·실측값·모터 시험자료를 대조해 작성했다. 적용된 수치와 아직 근사 또는 검토 단계인 내용을 함께 표시한다. 이번 정리에서 새로 기록한 사항은 CUG4-10 핀 중복 해소이며, 기존 URDF의 물리 수치를 추가로 변경하지 않았다.

**1. 발표의 출발점: 무엇을 하려는 작업인가?**

“실제 Hopper가 시뮬레이션 안에서도 비슷한 무게 배분과 회전 저항을 가지도록, 오래된 모델의 형상·물성·구동기 값을 최신 CAD와 실측에 맞춰 보정하고 있다.”

URDF 안의 정보를 아래처럼 나누면 설명하기 쉽다.

| 정보 | 쉬운 의미 | 이번 작업의 예 |
|---|---|---|
| visual | 화면에 보이는 겉모습 | S/L 연결봉에 맞는 mesh 선택 |
| joint·constraint | 어디를 중심으로 돌고, 링크가 어떻게 연결되는가 | 실제 연결봉 길이에 맞춘 폐루프 기준 자세 |
| mass | 얼마나 무거운가 | Body, Foot 실측 질량 반영 |
| COM | 무게가 어느 위치에 몰려 있는가 | CAD 질량중심을 링크 좌표로 변환 |
| inertia | 각 방향으로 회전시키기 얼마나 어려운가 | COM 기준 관성 텐서로 교체 |
| rotor_inertia | 모터·기어 내부 회전이 관절에 주는 추가 회전 저항 | 기어별 속도비로 출력축 등가 관성 계산 |
| effort·velocity | 모델에 설정된 토크·속도 한계 | 토크 시험점으로 effort 잠정 갱신 |
| collision | 바닥이나 다른 물체에 실제로 닿는 모양 | 밑창을 고려해 기존 Foot 박스 유지 |

질량이 거의 같더라도 COM이나 관성이 크게 달라질 수 있다. 예를 들어 같은 무게의 막대도 가운데를 잡고 돌릴 때와 끝을 잡고 돌릴 때 필요한 힘이 다르다. 이번 작업에서 관성이 크게 줄어든 항목은 부품이 그만큼 가벼워졌다는 뜻이 아니라, 기준점·축·부품 범위를 바로잡았다는 뜻이다.

**3. CAD 수치를 URDF에 넣는 공통 방법**

각 부품에 대해 “질량 하나를 복사”하는 방식으로는 부족하다. 다음 순서로 처리했다.

1. **선택 범위를 확인했다.** 부품 이름뿐 아니라 볼트·핀·베어링의 개수와 어느 부품에 붙어 함께 움직이는지 확인했다. 상위 어셈블리 값에 이미 포함된 부품을 다시 더하지 않는다.
2. **질량은 실측을 우선했다.** 실측한 부분은 그 값으로, 측정하지 않은 부분은 CAD 값으로 합성했다. 전체 질량만 측정된 경우 부품별 분포는 별도 가정으로 표시했다.
3. **좌표계를 맞췄다.** CAD의 X/Y/Z와 URDF의 X/Y/Z가 같다고 가정하지 않고 원점·회전축·핀 위치로 대응을 확인했다.
4. **COM 기준 관성을 사용했다.** SolidWorks의 “질량 중심에서 계산되며 출력 좌표계에 맞추어집니다” 아래 Lxx…Lzz 블록을 기준으로 했다. 맨 아래 원점 기준 Ixx…Izz를 COM 관성으로 그대로 넣지 않는다.
5. **단위와 관성곱 부호를 변환했다.** g→kg는 0.001, mm→m는 0.001, g·mm²→kg·m²는 1e−9를 곱한다. 받은 보고서의 양의 관성곱은 물리 관성 행렬의 비대각항으로 변환한 뒤 축 회전을 적용했다.
6. **합성하거나 분리할 때 평행축정리를 적용했다.** 서로 다른 위치의 부품 관성을 그냥 더하거나 빼지 않고, 공통 기준점으로 옮긴 뒤 합산했다.
7. **결과의 물리적 일관성을 검사했다.** 질량 양수, 관성 행렬 대칭성, 양의 주관성, 주관성 삼각부등식, 합산 COM·관성 복원을 확인했다.

수식이 필요한 청중에게는 다음만 보여주면 된다. CAD→URDF 회전 R, 원점 이동 t일 때:

- COM 변환: c_URDF = R c_CAD + t
- COM 관성 축 변환: I_URDF = R I_CAD Rᵀ
- COM에서 거리 d만큼 떨어진 기준점의 관성: I_O = I_COM + m[(dᵀd)E − ddᵀ]

여기서 E는 3×3 단위행렬이다. 마지막 항 때문에 원점 기준 관성이 COM 기준보다 크게 나올 수 있다.

받은 보고서에서는 L/I 비대각항 차이도 질량과 COM의 곱으로 확인할 수 있다. 예를 들어 Thigh 입력부의 X·Z COM 곱은 양수이고 보고된 Ixz−Lxz도 양수다. 이 보고서의 양의 관성곱 값을 물리 행렬의 −∫xz dm 성분으로 옮길 때 부호 변환이 필요한 근거다. 다른 내보내기 옵션에서는 표기 규칙을 다시 확인해야 한다.

주관성축의 이름도 주의해야 한다. `Iz = (0,1,0)`은 “세 번째 주관성축이 CAD Y 방향”이라는 뜻이다. 이름에 z가 있다고 CAD Z축 또는 URDF Z축 관성으로 넣는 것이 아니다. D110/D151에서 회전축 방향의 Lyy를 확인한 이유다. SolidWorks는 관성 표기 옵션을 제공한다. [SolidWorks 공식 옵션 설명](https://help.solidworks.com/2021/english/api/swconst/ToolsEvaluateMassPropertiesOptions.htm)

전체 질량 변화가 작아도 내부 무게 배분과 관성은 많이 바뀌었다. 실물 전체 14 kg 기준으로는 아직 1.041371 kg의 차이가 있다. 이 차이를 전부 케이블이나 밑창으로 간주해 임의 배분하지 않았다.

**Body / Temp_Weight**

덤벨은 1 kg짜리 세 개이므로 3 kg을 유지하고, 전체 실측 3.38 kg에 맞췄다. 현재 합성 계산은 CAD 부속 0.063884 kg을 유지하고, body1+body2를 CAD 0.11 kg에서 0.316116 kg으로 보정한다.

3.000000 + 0.063884 + 0.316116 = 3.380000 kg

전체 질량은 실측으로 정해졌지만 추가 질량이 body1+2에 분포한다는 것은 근사다. 부품별 실측이 모두 끝났다는 뜻은 아니다. COM 높이는 링크 기준 46.728→45.1062 mm, Ixx는 0.010710→0.00418110 kg·m²로 갱신됐다. Body 연결 joint의 위치와 기존 구형 visual/collision까지 새 CAD로 바꾼 것은 아니다.

**Foot**

실측 837 g은 foot_2, 볼트 8개, 부착된 타이어·고무 밑창을 모두 포함한다. 볼트만 48 g이므로 789 g은 ‘발 본체+밑창’이며, 맨발 CAD 부품만의 무게가 아니다.

현재 Foot 질량은:

0.929141 kg(CAD 전체) − 0.724284 kg(CAD에서 측정 대상 부분) + 0.837000 kg(같은 대상의 실측) = **1.041857 kg**

측정하지 않은 나머지 0.204857 kg은 CAD 값을 사용했다. 밑창 질량을 다시 더하지 않았다. 실측과 CAD 부분 질량의 차이 112.716 g을 밑창만의 무게라고 단정할 수도 없다.

Foot COM·관성도 이전 값에서 바뀌어 있지만, 선택 CAD 부분에 추가 질량을 분포시킨 추정이다. 밑창 자체의 질량·위치, 물성 보고 좌표계와 STEP 기준 좌표계의 일치는 추가 확인 대상이다. 따라서 **Foot 질량 보정의 근거가 COM·관성 분포까지 전부 실측했다는 뜻은 아니다.**

**Universal**

NSK_7001AW 베어링 4개가 포함된 CAD 값을 확인했다. CAD 209.57 g과 기존 URDF 209.567 g은 보고서 반올림 범위여서 질량은 유지했다. CAD축을 URDF축으로 맞춰 Ixx를 **0.000480→0.00004785009 kg·m²**로 수정했다.

이전 값은 Ixx > Iyy+Izz여서 강체 주관성의 물리 조건을 만족하지 않았다. 현재 값은 이 조건을 만족한다. 처음 작성 과정의 실수를 직접 본 것은 아니지만, 약 10배의 자릿수 차이를 바로잡은 구체적인 사례다.

**Calf와 좌우 ankle input**

Calf는 질량 3.41969 kg, COM (3.95, 0.01, −144.09) mm와 COM 기준 관성으로 갱신했다. Ixx는 0.104136→0.03144105, Iyy는 0.106810→0.03453173 kg·m²다. 큰 감소를 “실제 Calf가 70% 가벼워졌다”라고 설명하면 안 된다. 전체 질량은 오히려 조금 증가했다.

좌우 input은 각각 132.288→118.360 g으로 수정했고 COM과 6개 관성항도 갱신했다. 좌우 미러 부품에서는 일부 비대각항 부호가 반대로 나와야 하므로 같은 행렬을 그대로 복사하지 않았다.

**5. S/L 연결봉: 길이와 관성을 각각 보정**

먼저 “CAD의 길이가 맞으면 기존 mesh를 쓸 수 있지 않느냐”를 실제 파일에서 확인했다. 바운딩박스의 전체 길이 대신 **관절 중심 사이의 거리**를 비교했다.

| 길이 자료 | S mm | L mm |
|---|---:|---:|
| 실측 | 202 | 320 |
| STEP 관절 중심 거리 | 202.000000 | 320.000000 |
| 기존 Hopping1 mesh | 198.004639 | 316.000841 |
| 패키지에 이미 있던 V1 mesh | 201.996969 | 319.998015 |

V1 mesh의 중심 거리가 실물·STEP과 맞아서, S/L visual이 V1 파일을 참조하도록 바꿨다. 새 DAE를 생성한 것이 아니라 패키지 안에 이미 있던 파일을 선택한 것이다. 모든 표면 형상까지 최신 CAD와 동일하다고 인증한 것은 아니다.

또한 202/320 mm 연결봉이 현재 연결점에 맞도록 폐루프 constraint의 **nominal_config**, 즉 기준 자세의 관절각을 조정했다. 단순히 화면 모양만 바꾼 작업과 구분해야 한다. joint 원점·회전축과 constraint 핀 anchor 위치는 유지했다.

관성은 별도로 다시 계산했다. URDF는 봉과 Dice를 각각의 링크로 표현한다. Dice는 여기서 연결봉 끝의 작은 유니버설 관절 중간 부품에 붙인 이름이다.

CAD 전체 연결봉 어셈블리 물성을 봉에 통째로 넣으면 이미 URDF에 존재하는 Dice를 두 번 세게 된다. 그래서 같은 좌표계·기준점으로 변환한 CAD 합성 관성에서 기존 Dice의 기여를 뺀 뒤 봉의 COM과 관성을 구했다.

| 항목 | 이전 | 현재 |
|---|---:|---:|
| S COM z, mm | 83.422 | 84.408543 |
| L COM z, mm | 137.377 | 138.158415 |
| S Ixx, kg·m² | 0.001708 | 0.000800961552 |
| S Iyy, kg·m² | 0.001714 | 0.000807444803 |
| L Ixx, kg·m² | 0.005596 | 0.002425260970 |
| L Iyy, kg·m² | 0.005602 | 0.002431743355 |

S의 주요 횡방향 관성은 약 53%, L은 약 57% 감소했다. 반면 COM 변화는 약 0.99/0.78 mm 수준이다. 이는 “COM이 크게 움직여서 관성도 크게 달라졌다”는 상황과는 다르다. 기존 합성 관성값과 CAD COM 관성의 불일치를 보정한 것이다.

봉+Dice를 다시 합치면 기준 자세에서 제공 CAD의 COM·관성이 복원되는 것을 수치로 확인했다. 다만 Dice 단독 물성과 부싱 소속은 잠정값이므로, 두 움직이는 강체를 각각 완전히 식별한 최종 모델은 아니다.

**6. 모터 내부 관성: CAD에서 무엇을 얻을 수 있는가?**

SolidWorks는 형상과 설정된 밀도·질량을 이용해 **기계적 질량관성**을 계산할 수 있다. 회전자를 직접 가속하는 실험을 하지 않아도 CAD 기반 추정이 가능하다. 그러나 이 값이 실험으로 식별한 실제 로터 관성이나 권선의 전기적 성능을 뜻하지는 않는다.

스테이터와 하우징도 다리와 함께 움직이므로 링크 질량·관성에 들어간다. 로터·기어의 상대적인 내부 회전은 관절에서 추가 관성으로 느껴지므로 별도로 계산했다.

출력 관절보다 N배 빠르게 회전하는 부품의 환산 관성은 J×N²다. 예를 들어 20배 빠르게 돌면 같은 부품 관성이 출력축에서는 400배로 반영된다. 유성기어는 자기 축 주위의 **자전**과 중심축 주위를 도는 **공전**을 나누어 계산한다.

현재 `rotor_inertia`는 다음의 합을 의미한다.

J_eq = Σ J_spin,i × (ω_i/ω_out)² + Σ m_i r_i² × (ω_carrier/ω_out)²

이 모델은 하우징 고정 조건에서의 출력축 등가 관성을 중심으로 한 근사다. 내부 모든 물체와 다리 운동 사이의 결합항을 가진 상세 다물체 모델은 아니다.

**D110 ankle**

썬 20T, 유성 32T, 고정 링 84T 구성에서 감속비는 5.2:1이다. 출력 속도 1을 기준으로 모터는 5.2, 유성기어의 절대 자전 속도는 −1.625다. 로터·썬·엔코더 링, 유성 4개 자전·공전, 캐리어·출력부·포함 볼트를 합산했다.

J_eq = 0.00022457×5.2² + 4×600.91×1e−9×(−1.625)² + 4×0.01423×0.0156² + 0.00002429  
= **0.00611686196 kg·m²**

출력부 물성에 이미 들어간 볼트를 다시 추가하지 않았다. D110도 내부 베어링 내·외륜 등의 상대 회전은 아직 별도로 모델링하지 않았다.

| 단계 | 발목 1개당 rotor_inertia kg·m² |
|---|---:|
| 확인한 초기 두 파일 | 0.01280000000 |
| 업로드 당시 20260820 파일 | 0.00535392000 |
| 현재 CAD 기어열 계산 | 0.00611686196 |

현재 값은 초기 두 파일보다 약 **52.21% 감소**, 8월 중간값보다 약 **14.25% 증가**했다. 비교 기준이 다르기 때문에 서로 모순되지 않는다. 현재 계산에는 단순 로터 환산보다 더 많은 내부 부품이 포함된다.

대화에서 다룬 이전 8:1→현재 5.2:1이라는 조건만 비교하면, 같은 모터 토크에서는 출력 토크가 0.65배, 같은 모터 속도에서는 출력 속도가 약 1.54배가 된다. 같은 로터의 환산 관성은 0.4225배다. 하지만 모터·기어 자체도 달라졌고 속도 시험은 없으므로 **실제 새 구동기가 정확히 1.54배 빨라졌다고 확인한 것은 아니다.** 오래된 XML의 관성 숫자 하나만으로 그 당시 기어비를 독립적으로 입증할 수도 없다.

**D151 knee**

D151의 3K 복합 유성기어는 고정 링 99T, 썬 33T, 복합 유성 33T/24T, 출력 링 90T를 기준으로 운동학을 계산했다.

ω_s = 4ω_c  
ω_out = [1 − (99×24)/(33×90)]ω_c = ω_c/5

따라서 출력 속도 1에 대해 모터 20, 캐리어 5, 유성 자전 −10이다. “캐리어가 5배로 돈다”는 뜻이지, 별도의 독립된 5:1 감속기 두 단을 임의로 가정한 것은 아니다.

V1 두 개, V2 두 개가 각각 마주보는 구성과 두 버전의 다른 CAD 관성을 반영했다. 핀과 볼트는 메이트의 실제 연결 상대와 사용자 설명으로 속도 그룹을 나눴다. 서브어셈블리 이름에 메이트됐다는 사실만으로 어느 회전체에 속하는지 단정하지 않았다.

| D151 반영 항목 | 출력축 환산 기여 kg·m² |
|---|---:|
| 모터·썬·엔코더 링 | 0.369348344000 |
| 썬 LPSTAG 핀 2개 | 0.000028712000 |
| 캐리어 | 0.002725546750 |
| 캐리어 LPSTAG 핀 4개 | 0.000016561500 |
| 캐리어 볼트 8개 | 0.000204492000 |
| 유성 V1/V2 각 2개 자전 | 0.001664938000 |
| 유성 4개 공전 | 0.002923050240 |
| 정리된 출력 3부품 그룹 | 0.000272416420 |
| 출력 LPSTAG 핀 2개 | 0.000001354870 |
| MTA 베어링 8개 공전 | 0.001073318400 |
| **합계** | **0.378258734180** |

이전 URDF의 0.36880에서 약 2.56% 증가했다. 201.80 g으로 받았던 혼합 선택 그룹은 그대로 넣지 않고, 194.17 g 출력 3부품 그룹과 확인된 출력 핀을 사용했다. 베어링의 공전은 반영했지만 내·외륜·전동체·케이지의 개별 자전까지 완성한 것은 아니다.

**D151 수치는 감속기 출력축 기준이라는 점이 중요하다.** 현재는 이 값을 knee joint에 직접 넣고 있으므로, Thigh 전달 링크를 통과한 감속기 출력각과 실제 무릎각의 관계를 검증해야 한다. 전달 속도비 a=dθ_output/dq_knee가 1이 아니면 knee 기준 관성은 J_eq×a², 토크 전달은 해당 1차 비율로 환산해야 한다. 별도 움직이는 링크로 출력부를 모델링할 때는 기존 rotor 항과 동일한 운동을 중복 계산하지 않게 재분리해야 한다.

`rotor_inertia`는 여기서 사용하는 RaiSim의 URDF 확장이다. RaiSim은 이 값을 질량행렬 대각에 추가하며, 감속비 제곱은 입력 전에 계산해야 한다. C++의 `setRotorInertia()`로 덮어쓸 수 있고 자이로 효과는 생략하는 근사다. 따라서 다른 엔진에서도 같은 의미로 자동 적용된다고 가정하지 않는다. [RaiSim 공식 설명](https://raisim.com/sections/ArticulatedSystem.html)

**7. 모터 토크 시험: 반영한 것과 반영하지 못한 것**

현재 URDF 주석에 남은 시험 해석은 정·역방향 끝점 토크 절댓값 평균이다. D110 약 16.52 N·m @60 A, D151 약 27.5166 N·m @110 A를 사용했다. 사용자 전달 내용의 “약 16.5까지”, “27까지 측정했고 더 나올 수도 있음”과 같은 성격의 자료다.

| 설정 | 이전 | 현재 | 해석 |
|---|---:|---:|---|
| D110 effort, N·m | 150 | 85.9 | 16.52×5.2, 감속기 손실 미반영 |
| D151 effort, N·m | 600 | 550.3 | 27.5166×20, 감속기 손실 미반영 |
| D110 velocity, rad/s | 18.3 | 18.3 | 기존값 유지. 실측 최고속도 아님 |
| D151 velocity, rad/s | 10.11 | 10.11 | 기존값 유지. 실측 최고속도 아님 |

이 effort 값들은 **시험에서 도달한 모터측 토크를 바탕으로 한 잠정 출력축 설정**이다. 실제 최대 출력토크의 보장값, 연속토크 또는 보수적으로 검증된 안전 한계가 아니다. 감속기 효율을 아직 적용하지 않았기 때문이다. 정지 토크 시험만으로 최고속도·로터 관성·열적 한계를 구할 수 없다.

velocity는 현재 주석상 65.1 V 전제의 추정값을 유지한다. 새 속도 실험으로 갱신했다고 설명하지 않는다. 전류 제한, 발열, 토크–속도 곡선, 제어 지연, 마찰·효율을 모두 식별한 상태도 아니다. URDF를 읽은 실행 코드가 값을 덮어쓰거나 별도 제한을 적용하는지도 확인이 필요하다.

발목 effort는 모터가 구동하는 좌우 **ankle input joint 각각의 설정**이며 발목 pitch 또는 roll 단일 축의 최대 토크와 바로 같은 값은 아니다. 병렬 링크의 자세와 기구학에 따라 발에 전달되는 pitch/roll 토크가 달라진다.

**8. Foot collision과 실제 밑창**

발은 평탄부 박스와 기울어진 발끝 박스 두 개를 사용한다.

| 박스 | 크기 mm | 중심 위치 mm | 방향 |
|---|---|---|---|
| 평탄부 | 200×100×30 | (−20, 0, −65) | 기울기 없음 |
| 발끝 | 55×100×30 | (120, 0, −45) | pitch −0.5 rad, 약 −28.65° |

평탄부 바닥은 발목 기준 아래 80 mm다. CAD 본체의 바닥보다 약 6.35 mm 내려와 있는 점은 실물에 붙인 타이어·고무 밑창과 부합한다. 사용자 확인에 따라 기존 collision을 유지했다.

발끝은 둥근 CAD 형상을 박스로 근사한 모델이다. 실제 접촉 면적, 끝부분 굴러넘어감, 고무 압축에 따른 높이는 정확히 재현하지 않는다. 따라서 “접촉 모델을 실측으로 완성했다”가 아니라 “밑창을 고려하면 기존 단순 형상이 합리적인지 검토하고 유지했다”라고 설명한다.

이전 무날짜 파일의 발끝 60 mm와 현재 55 mm는 차이가 있지만, 55 mm는 이미 20250311 파일에 존재했다. 최근 보정 작업에서 발끝을 60→55 mm로 바꾼 것은 아니다.

**9. Thigh: 지금 진행 중인 마지막 큰 분리 작업**

CAD 어셈블리 한 개가 URDF의 강체 링크 한 개와 반드시 같지는 않다. 어셈블리 내부에서 부품끼리 상대 회전하면 부품이 어느 움직임에 속하는지 먼저 나눠야 한다. SolidWorks의 회전 잠금 체크박스만으로 실제 고정 여부를 판정하지 않고 사용자 실물 설명을 우선했다.

최근 확인한 내용은 다음과 같다.

| 구성 | 확인된 내용 |
|---|---|
| Thigh_link_input_verU1 | 296.74 g, 내부 M10 볼트 포함 |
| input_frame_2 외부 M5 볼트 | 6개, 총 22.32 g |
| D151_K_output_1에 붙은 CUG4-10 | 실제 2개, 총 2.10 g |
| Thigh_link_verU1 | 72.76 g |
| YT2015 베어링 | 각 23.50 g, 두 개 47.00 g |
| thigh_link_3와 thigh_link_2 | 사용자 설명상 잡혀 있으며 YT2015가 상대 회전을 허용 |

CUG4-10 `<2>`가 `<3>`와 중복이었고 사용자가 수정했다. 실제 핀은 `<3>`, `<4>` 두 개로 기록했다. 앞서 D151 내부 관성에 사용한 LPSTAG 핀과 이번 CUG 핀은 별개이므로 혼동하지 않는다.

입력 어셈블리+M5 6개는 319.06 g, 여기에 CUG 출력 핀 두 개까지 포함하면 321.16 g이다. 긴 연결봉+YT 두 개는 119.76 g이다. 이 수치는 부품 장부의 소계이며, 나머지 D151 출력부까지 포함한 최종 강체 물성이 아니다.

최신 YT 두 개의 COM과 기존 STEP 배치가 서로 다른 자세를 나타낸다. 관성으로 복원한 베어링 중심 간 거리 약 141.3 mm는 일치하지만, 자세를 통일하지 않은 채 전체 Thigh에서 부분 물성을 빼면 잘못된 결과가 된다.

따라서 **현재 Thigh는 질량 4.29025 kg과 기존 COM·관성 수치를 유지한다.** 제공 CAD 전체 질량 4.06749 kg을 바로 덮어쓰지 않았다. 새 분리 모델에 핀 중복을 아직 수치로 추가한 적도 없으므로, 이번 중복 확인만으로 현재 총질량에서 1개 핀 질량을 다시 빼지 않았다.

남은 핵심은 같은 기준 자세에서 부품을 배치하고, 입력부·연결봉·고정부의 움직임을 정한 뒤 knee의 전달 관계까지 함께 정리하는 것이다.

**10. 검증은 어디까지 했는가?**

| 검증 | 현재 범위 |
|---|---|
| 파일 비교 | 초기 계열 후보 2개, 업로드 당시 20260820, 현재 파일의 활성 XML 값 비교 |
| 구조 | 링크 11개·joint 10개 연결 구조 및 joint 원점·축 유지 확인 |

| 관성 | 변경한 텐서의 양의 주관성·삼각부등식 확인 |
| S/L 길이 | 실측·STEP·mesh의 관절 중심 거리 비교 |
| S/L 관성 | Dice+rod를 합쳐 CAD COM·관성을 복원 |
| 기어 관성 | D110·D151 항목별 합산으로 현재 rotor_inertia 재현 |
| Thigh 부분 자료 | 6개 보고서 주관성·행렬 일치와 베어링 간격 확인 |
| 실제 동작 | 이번 자료 검증에서 동적 시뮬레이션 및 실물 동작 비교는 수행하지 않음 |

수치 계산에서 COM 복원 오차가 1e−12 m보다 작다는 것은 **계산식이 서로 일치한다는 의미**다. CAD와 실물이 그 정밀도까지 일치한다는 측정 결과가 아니다. 원자료가 소수점 두 자리인 경우 출력 숫자를 많이 썼다고 물리적 정확도가 늘어나지는 않는다.

현재 8개의 링크 inertial 블록이 바뀌었다. Thigh와 Dice 두 개는 유지했다. 20260820 원본 대비 모든 collision, 모든 joint 위치·축·각도 범위·속도값·damping·friction은 유지했다. S/L mesh 두 참조, constraint nominal_config, 모터 3개 joint의 effort/rotor_inertia가 바뀌었다.

**11. 다음에 할 일의 우선순위**

1. **Thigh 움직이는 부품 분리와 knee 전달 관계 확정.** 지금 받은 자료와 중복 핀 정리를 사용해 같은 자세에서 질량·COM·관성을 합성한다. 감속기 출력축 관성을 knee joint에 직접 넣을 수 있는지도 함께 확인한다.
2. **전체 실물 14 kg과 링크 합계의 차이 추적.** 전장·케이블·브래킷·밑창 등 실제 포함 범위를 대조하고 위치까지 알 수 있는 항목부터 배분한다.
3. **Foot COM·관성의 좌표 및 밑창 분포 보강.** 837 g 총량은 이미 사용했으므로, 필요하다면 밑창 별도 질량·두께·설치 위치로 분포를 개선한다.
4. **Dice·베어링의 소속 정리.** S/L 합성값은 맞지만 각 움직이는 몸체의 분할을 더 정확히 한다.
5. **실행 중 적용값과 실물 응답 대조.** 파일 값이 실제 시뮬레이터에서 읽히는지 확인하고, 가능한 범위에서 정적 자세 토크·수동 진동·접촉 높이 등의 결과를 비교한다. 새로운 고전류 모터 시험이 있어야만 앞의 CAD 작업을 진행할 수 있는 것은 아니다.
